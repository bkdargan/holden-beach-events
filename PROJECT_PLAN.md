# Holden Beach Events Project Plan

## Phase 1 - Brunswick County Events
- Extract event URLs from Brunswick County Events
- Visit each event page
- Extract title, date, time, location, description
- Store results

## Phase 2 - Holden Beach Concert Schedule
- Extract summer concert schedule
- Create calendar events
- Avoid duplicates

## Phase 3 - Holden Beach Parks & Recreation
- Extract community events
- Extract seasonal events
- Add to event database

## Phase 4 - Duplicate Detection
- Compare title + date + location
- Skip existing events
- Update changed events

## Phase 5 - Google Calendar Automation
- Create events automatically
- Update events automatically
- Remove canceled events

## Phase 6 - Daily Updates
- Run GitHub Action daily
- Refresh all sources
- Update calendar
